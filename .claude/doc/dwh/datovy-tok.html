Detail kroků pipeline

1. Data Source (query na zdrojové DB)

SQL query uložena v tabulce data_source. DataSourceConsumer se připojí na zdrojovou DB (přes source_connection) a spustí query. Výsledek (raw řádky) putuje do dataToValuesQueue.

2. Import → DatasetValues

DataToValuesConsumer přijme raw data. Pro každý řádek namapuje sloupce na def_id, vytvoří dataset_entity a uloží hodnoty do dataset_values: (entity_id, def_id) → value. Stav entity: new nebo updated.

3. Transformace

TransformationConsumer načte pravidla data_transformation. Každé pravidlo: before_value → after_value. Upravené hodnoty se uloží zpět do dataset_values.

4. Obohacení (Enrichment)

EnrichmentConsumer načte data_enrichment pravidla. Lookup join: hodnota z entity X se hledá v jiném datasetu Y → přidá hodnotu z Y jako nové def_id.

5. Validace

ValidationConsumer kontroluje formáty, povinná pole, regex dle data_validation pravidel. Selhání → entita dostane stav invalid. Úspěch → stav valid.

6. Data Quality

DataQualityConsumer detekuje anomálie, duplicity, statistické odchylky dle data_quality_rule. Generuje reporty, nespoléhá jen na stav entity.

Stavy dataset_entity

new
  → (import)       → valid / invalid
      valid
        → (transformace) → transformed
            → (enrichment) → enriched
                → (validace)  → validated / invalid
                    validated → (publikace) → published

invalid → (oprava) → new (recycle)
locked  → nelze editovat
archived → historický záznam

Tok webového requestu (UI)

Browser → Latte HTML 
Browser
  → GET /data/dataset/detail/{id}
  → www/index.php
  → Bootstrap.php  (DI kontejner)
  → Nette Application router
  → DataModule\Presenters\DatasetPresenter::renderDetail($id)
      → DatasetManagerService::getDataset($id)
          → BaseRepository → EDA → PostgreSQL SELECT
      → render('DataModule/templates/Dataset/detail.latte', [...])
  ← HTML response

Tok REST API requestu

External systém → RabbitMQ job 
External systém
  → POST /api/rest/v1/actions/get-data/tournament_match
    Header: apiToken: <token>
  → www/index.php → detekuje 'api/rest'
  → Apitte Middlewares:
      ApiKeyAuthenticationMiddleware  (ověří token)
      LogApiMiddleware                (loguje)
  → ActionController::getDataAction($name)
      → ActionService::triggerImport(...)
          → RabbitMQ: masterQueue  (publish)
  ← JsonResponse { status: "queued", job_id: "..." }

Tok CLI / cron

cron → RabbitMQ → ETL pipeline 
Linux cron: * * * * * php bin/console.php app:job-queue
  → JobQueueCommand::execute()
      → Načte z DB: job_definition kde enabled=true AND cron vyšel
      → Pro každý job → publish do jobProcessQueue
  → (asynchronně) JobProcessConsumer → MasterConsumer → ... → publicationQueue
