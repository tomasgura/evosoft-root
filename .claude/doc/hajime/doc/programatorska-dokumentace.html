Příklad implementace controlleru

#[Path('/tournament')]
#[Tag('Tournaments')]
final class TournamentController extends BaseController
{
    #[Path('/list')]
    #[Method(IRequest::Get)]
    #[Negotiation('json', true)]
    #[Response('Success', '200')]
    public function list(ApiRequest $request, ApiResponse $response): ApiResponse
    {
        $list = $this->tournamentController->getActiveEntityCollection()->fetchAll();
        return $this->successEntityCollection($response, $list);
    }
}

7Integrace

Flexii (enterprise platforma)

Balíček: evosoftcz/flexii-connector – SSO autentizace a synchronizace závodníků z ČSJÚ. AES šifrování dat. Konfigurace v config/local.neon → flexiiConnector.*.

RabbitMQ (message broker)

Balíček: contributte/rabbitmq – asynchronní zpracování eventů a jobů. Konfigurace: rabbitmq_connection.

Riziko: Pokud je RabbitMQ nedostupné, chování závisí na fallback logice konzumentů – nutno ověřit.

EDA – Event-Driven Architecture

Balíček: evosoftcz/eda – workflow zpracování na bázi PostgreSQL eventů. Integrovaný Tracy panel. EventController v business vrstvě.

Rights systém

Balíček: evosoftcz/rights – granulární kontrola oprávnění. Použití: Rights::RIGHTS_MODULE_TOURNAMENT v startup() presenterů.

SMTP – e-maily

Nette Mail s SMTP. Service MailService – šablonové notifikace závodníkům. Konfigurace v config/local.neon → mailer.*.

PDF generátor

Balíček: mpdf/mpdf. Service PasswordPrintService generuje PDF přihlašovacích hesel pro scale/scoreboard/infopanel.

Hyperdrive – DB migrace

Interní balíček (Liquibase-based). Umístění: resources/hyperdrive/. Skupiny: structure/, basic-data/, dummy-data/, configurations/, version/.

public function startup(): void
{
    parent::startup();
    if (!($this->getUser()->isLoggedIn()
        && $this->getUser()->isAllowed(Rights::RIGHTS_MODULE_TOURNAMENT))) {
        $this->redirect(':Sign:in');
    }
}

10Migrace databáze

Struktura Hyperdrive

resources/hyperdrive/
├── structure/          # DDL migrace (tabulky, indexy, FK)
├── basic-data/         # Povinná aplikační data
├── dummy-data/         # Demo/testovací data (jen demo mód)
├── configurations/     # Konfigurační záznamy
└── version/            # Verze schématu

Příkazy

# Aplikovat migrace
php bin/console.php hyperdrive:start postgre

# Smazat celou DB (dev only!)
php bin/console.php hyperdrive:procedure postgre dropPostgre

# Makefile zkratky
make load     # = hyperdrive:start postgre
make reload   # = drop + load (kompletní reset)

Přidání nové migrace

  1. Vytvořit XML changeset v resources/hyperdrive/structure/XXXX_nazev.xml
  2. Spustit php bin/console.php hyperdrive:start postgre
  3. Ověřit shodu s ORM Mapperem nové entity
