Datový model — DWH

Databáze: PostgreSQL 17 (alternativně Oracle 18c XE)
Schéma: public (core tabulky), export (materializované pohledy)
Migrace: Liquibase (Hyperdrive), resources/hyperdrive/structure/

Klíčové tabulky

Konfigurace a připojení

TabulkaObsah
lookup_languageJazyky aplikace (cs, en, de, ...)
source_connectionPřipojení na zdrojové DB (host, port, db, user, šifrované heslo)
data_sourceSQL query na zdrojové DB (name, connection_id, sql, schedule, priorita)
appuserUživatelé aplikace (login, password hash, role)
applicationAPI tokeny pro REST API

Dataset a definice

TabulkaObsah
datasetDefinice datové sady
dataset_partFyzická část datasetu (odpovídá jedné tabulce/struktuře)
dataset_part_definitionSloupec/pole datasetu (name, data_type, required, order, ...)

Data (hodnoty) — největší tabulky

TabulkaObsah
dataset_entityJeden datový záznam (řádek v datasetu). Status, historization flag.
dataset_valuesHodnoty: (entity_id, def_id) → value (TEXT). Miliony řádků.

Procesní pravidla

TabulkaObsah
data_transformationPravidla transformace (before_value → after_value)
data_enrichmentEnrichment mapování (lookup z jiného datasetu)
data_validationValidační pravidla (required, regex, format, min/max)
data_quality_rulePravidla pro detekci anomálií
publicationDefinice cílového exportu (view, Kafka, file, ...)

Organizace a joby

entity_group_categoryKategorie skupin (hierarchie)

Stavy dataset_entity

new        → čerstvě importovaný záznam
valid      → prošel základní validací
invalid    → selhal validaci
transformed → prošel transformacemi
enriched   → prošel enrichmentem
validated  → prošel kompletní validací
published  → publikován do cíle
locked     → zamčen (nelze editovat)
archived   → historický záznam

Databázové migrace (Liquibase)

resources/hyperdrive/
  structure/              # Core schéma changesets (2022–2026)
    2022-01-01-init.xml   # Iniciální schéma
    2023-*.xml, 2024-*.xml, 2025-*.xml, 2026-*.xml
  basic-data/             # Lookup seedy
  customer-data/c{N}/     # Per-customer rozšíření
  playbook.xml            # Orchestrace pořadí migration groups

Spuštění: php bin/console.php hyperdrive:start postgre

Šifrování citlivých dat

Hesla v source_connection jsou šifrována (AES). Klíč iv a secret jsou v config/local.neon. Dešifrování provádí DataSourceService za runtime.
