1. Flexii API

Třída: src/Repository/External/FlexiiRepository.php
Konfigurace: config/packages/flexii_connector.yaml

Environment proměnné

FLX_CONNECT_API_URL=https://...
FLX_CONNECT_API_TOKEN=...
FLX_CONNECT_API_DEBUG=0
FLX_CONNECT_CRYPTO_ENABLED=1
FLX_CONNECT_CRYPTO_IV=...
FLX_CONNECT_CRYPTO_SECRET=...

Co se stahuje

MetodaPopis
getTournamentsFromFlexii()Seznam turnajů
getClubsFromFlexii()Seznam klubů
getClubLogoFromFlexiiIfUpdated($uid)Logo klubu (jen při změně)
getTournamentResultFilesFromFlexiiIfUpdated($uid)Výsledkové soubory turnaje
Synchronizace běží přes CLI command (cron), ne za runtime requestu. Porovnávají se dt_upd_attributes z API vs. timestamp lokálního souboru.

2. Hajime API

Třída: src/Repository/External/HajimeEndpoint.php
Service: src/Service/HajimeService.php
Env: HAJIME_URL

Endpointy

EndpointMetodaPopis
/api/open/tournament/{uid}/subcategorygetSubcategoryJSON()Věkové kategorie
/api/open/tournament/{uid}/subcategory-shuffle/{id}getShuffleJSON()Losovací tabulka
/api/open/tournament/{uid}/subcategory-matches/{id}getMatchesJSON()Live zápasy
/api/open/tournament/{uid}/subcategory-results/{id}getResultsJSON()Výsledky podkategorie
/api/open/tournament/{uid}/results/{agecategory_id}getAgeCategoryResultsJSON()Výsledky věkové kategorie
SSL verifikace je vypnuta (setSslVerifyHost(false), setSslVerifyPeer(false)) — integrace je určena pro interní síť.
Interface ITournamentDetailRepository má dvě implementace:
  • TournamentDetailHajimeRepository — pro live turnaje (čte z Hajime API)
  • TournamentDetailDWHRepository — pro archivní turnaje (čte z DWH)

3. PostgreSQL DWH

ORM: EDA (Evosoft Data Access)
Konfigurace: config/packages/eda.yaml
Přístup: Read-only (SELECT)

Environment proměnné

DATABASE_NAME=...
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USER=...
DATABASE_PASSWORD=...
Tabulky jsou materializované pohledy — refresh zajišťuje externí ETL. Aplikace do DWH nepíše.

4. Export souborů

PDF — mPDF

  • Metoda: ExportService::exportResultsToPdf()
  • Formátování: barvy medailí, borders, header řádky s info o turnaji
  • Tmp soubory: var/tmp/

XLSX — PhpSpreadsheet

  • Metoda: ExportService::exportResultsToXlsx()
  • Více listů — jeden list per věková kategorie

Životní cyklus exportního souboru

1. ExportService → vygeneruje soubor do var/tmp/{filename}
2. Controller   → BinaryFileResponse (stream do browseru)
3. Soubor zůstane v tmp (cleanup by měl řešit cron)

5. Stahované soubory od pořadatelů

  • Výsledkové soubory turnajů (PDF, XLSX) se stahují z Flexii API
  • Ukládají se do public/files/tournaments/{tournament_uid}/
  • Nabízeny ke stažení přes download_result_file endpoint
