Hajime – Judo Tournament Management System

PHP webová aplikace pro správu judo turnajů (přihlášky, vážení, pavouk zápasů, scoreboard).

Stack: PHP 8 Nette 3.1 Nextras ORM 4 PostgreSQL 15 Latte 3 Apitte REST API

Požadavky

  • Docker + Docker Compose
  • PHP 8.x + Composer
  • Přístup k síti evs_dev_net (interní Evosoft Docker network)
  • Přístup k registry.evosoft.cz (Docker image)

Lokální spuštění

1. Naklonovat repozitář

git clone <repo-url>
cd judo-external-hajime

2. Nakonfigurovat prostředí

cp config/local.example.neon config/local.neon

Otevřít config/local.neon a vyplnit:

parameters:
    databaseConnection:
        host: postgresql_15          # název Docker služby
        database: judo
        username: app
        password: 1234

    flexiiConnector:
        apiUrl: 'https://...'
        apiToken: '...'
        cryptoIv: '...'
        cryptoSecret: '...'

    apiTokens:
        - 'vas-api-token'

    mailer:
        host: smtp.example.com
        username: ''
        password: ''

3. Spustit Docker

docker-compose up -d

Aplikace běží na hostu judo.loc (přidat do /etc/hosts: 127.0.0.1 judo.loc).

4. Nainstalovat PHP závislosti

composer install

5. Inicializovat databázi

# Spustit všechny migrace
php bin/console.php hyperdrive:start postgre

# Volitelně: nahrát vývojová testovací data
# (pouze v dev prostředí)
make reload

6. Ověřit funkčnost

Otevřít v prohlížeči: http://judo.loc

Vývojové prostředí

Tracy debugger

Zapnout Tracy debug mode jedním ze způsobů:

# Varianta A – soubor v rootu projektu
touch .debug

# Varianta B – v config/local.neon
tracy:
    debugMode: true

Databáze – reset

make reload    # drop + nová inicializace DB
make load      # jen inicializace (bez drop)

Ruční migrace

# Aplikovat nové changesets
php bin/console.php hyperdrive:start postgre

# Smazat celou DB
php bin/console.php hyperdrive:procedure postgre dropPostgre

REST API

Base URL: /api/rest/

Autentizace: hlavička X-Api-Token: <token> nebo query parametr ?token=<token>

Tokeny jsou definovány v config/local.neon → parameters.apiTokens.

OpenAPI dokumentace je dostupná na /api/rest/doc (pouze v dev módu).
