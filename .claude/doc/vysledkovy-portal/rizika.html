Detail rizik

8. Chybějící automatizované testy Vysoká

Popis: V src/ nejsou žádné unit ani integration testy. PHPStan a Playwright jsou nakonfigurované, ale Playwright testy nebyly nalezeny.

Dopad: Regrese nejsou automaticky detekovány, každá změna je riziková.

Doporučení: Přidat unit testy alespoň pro Services a Repository vrstvu. Prioritně pokrýt složitou logiku (cache, export, kategorie).

6. Hajime API jako Single Point of Failure Střední

Popis: Pro live turnaje je jediným zdrojem dat Hajime API. Výpadek = prázdné stránky.

Dopad: Viditelný v době konání turnaje — nejkritičtější moment pro uživatele.

Doporučení: Přidat graceful degradaci — zobrazit poslední cached data nebo hlášku o výpadku.

3. Cache invalidace Střední

Popis: Data jsou cachována s fixním TTL. Při aktualizaci v DWH nebo Flexii se cache neinvaliduje.

Dopad: Zpožděné zobrazení aktuálních výsledků po synchronizaci.

Doporučení: Manuální invalidace cache po Flexii syncu, nebo kratší TTL pro kritická data.

5. Flexii synchronizace bez retry Střední

Popis: CLI commandi nemají retry logiku. Chyba API = ztráta dat pro daný run.

Dopad: Chybějící loga/soubory, obnoví se až při dalším cron spuštění.

Doporučení: Přidat retry s exponenciálním backoffem, logovat chyby per-turnaj/klub.

1. SSL verifikace vypnuta Střední

Popis: HajimeEndpoint má vypnutou SSL verifikaci (setSslVerifyHost(false)).

Dopad: Možnost MITM útoku v interní síti.

Doporučení: Ověřit certifikát Hajime API a SSL verifikaci zapnout.

7. Proprietární ORM EDA Střední

Popis: EDA je interní Evosoft knihovna bez veřejné dokumentace.

Dopad: Vyšší onboarding čas pro nové developery.

Doporučení: Zajistit interní dokumentaci EDA, komentáře u nestandardního chování.

4. Tmp soubory (export) Nízká

Popis: ExportService ukládá exportní soubory do var/tmp/ a nemaže je.

Dopad: Postupné plnění disku.

Doporučení: Přidat cron job pro mazání starých souborů z var/tmp/.

2. Závislost na externím ETL Nízká

Popis: DWH tabulky aktualizuje externí ETL. Při jeho selhání aplikace zobrazuje stará data bez varování.

Dopad: Neaktuální výsledky pro uživatele.

Doporučení: Zobrazit datum posledního refreshe DWH v UI nebo admin rozhraní.
