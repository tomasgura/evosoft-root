Uživatelská dokumentace — DWH

K čemu DWH slouží

  • Definovat datasety — struktura dat
  • Konfigurovat datové zdroje — odkud se data načítají
  • Nastavit pravidla zpracování — transformace, obohacení, validace
  • Spustit import dat — načtení ze zdrojů a zpracování
  • Publikovat data — export do cílových systémů
  • Monitorovat stav zpracování a řešit chyby

Workflow — jak naimportovat data

  1. Nadefinuj datový zdroj (Admin → Data Sources)
    Vyber připojení na zdrojovou DB, zadej SQL query, nastav plán.
  2. Nadefinuj pravidla (Admin → Transformace / Validace / Enrichment)
    Transformace, lookup join, kontroly formátů.
  3. Spusť import (Data → Dataset → „Načíst data")
    Data se zařadí do fronty a zpracují asynchronně.
  4. Zkontroluj výsledky (Data → Dataset → přehled entit)
    Stav každé entity: valid / invalid. Chybové hlášky u invalid.
  5. Spusť publikaci (Data → Dataset → „Publikovat")
    Data se exportují do cílového systému.
