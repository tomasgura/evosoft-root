1. Zdrojové databáze

Podporované typy: PostgreSQL, Oracle, MySQL, MS SQL Server, soubory (CSV/XLSX), external API

  1. source_connection obsahuje: driver, host, port, db, user, šifrované heslo
  2. Hesla jsou šifrována AES (klíče iv + secret v config/local.neon)
  3. DataSourceService dešifruje heslo za runtime a otevře spojení
  4. Spustí SQL query z data_source.sql
  5. Výsledek (raw řádky) pošle do RabbitMQ

2. RabbitMQ (interní pipeline)

3. Kafka (streaming výstup)

publications:
  dev_kafka:
    brokers: kafka-host
    port: 9092
    group: dwh-group

Publikace se konfiguruje v tabulce publication (typ: kafka, topic: ...). PublicationConsumer pošle JSON zprávu na definovaný topic.

4. REST API — příjem (inbound)

Prefix: /api/rest/v1/ · Auth: header apiToken

EndpointPopis
POST /api/rest/v1/actions/get-data/{name}Spustí import pro daný dataset
POST /api/rest/v1/publications/{id}/runSpustí publikaci
GET /api/rest/v1/datasets/{id}Metadata datasetu

5. SMTP (email)

mailer:
  mailFrom: xxx@xxx.cz
  host: smtp.host
  username: user
  password: pass
  secure: ssl

Emaily se odesílají při chybách v ETL pipeline, dokončení importu a systémových alertech.

6. Liquibase / Hyperdrive

Hyperdrive je wrapper nad Liquibase (Java). Spouští changeset XML soubory v pořadí. Tracking: tabulka DATABASECHANGELOG. Podporuje PostgreSQL i Oracle.

Spuštění: php bin/console.php hyperdrive:start postgre
