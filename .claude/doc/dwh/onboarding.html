Onboarding pro nového developera — DWH

DWH je ETL platforma. Přijímá data z externích zdrojů, zpracovává je asynchronně přes RabbitMQ pipeline a publikuje do cílových systémů. Ostatní Evosoft aplikace (Judo výsledkový portál, ...) čtou data z materializovaných pohledů, které DWH spravuje.

Klíčové koncepty

ETL Pipeline přes RabbitMQ

Celý datový tok (import → transformace → validace → publikace) běží asynchronně přes RabbitMQ fronty. Žádný krok nevolá další krok přímo — vždy přes zprávu do další fronty. Consumery běží jako background procesy (24/7).

EAV datový model

dataset_values má Entity-Attribute-Value strukturu: pro každý záznam je N řádků (N = počet sloupců datasetu). Flexibilní schéma, ale JOINy jsou nákladné.

Časté otázky

Q: Jak spustit import ručně?
Admin UI → tlačítko „Načíst data", nebo POST /api/rest/v1/actions/get-data/{name}.
Q: Jak spustit consumery lokálně?
make rabbitmq (spustí 9 consumerů) nebo jednotlivě:
php bin/console.php rabbitmq:staticConsumer masterConsumer 5000
Q: Jak spustit DB migrace?
php bin/console.php hyperdrive:start postgre
Reset celé DB (DESTRUKTIVNÍ!): make reload-postgre
Q: Kde se logují chyby?
log/exception.log a Tracy HTML dumpy v log/exception*.html
Q: Co je Hyperdrive?
Evosoft wrapper nad Liquibase (Java). Spouští XML changesets na DB. Nutné mít Java runtime.
