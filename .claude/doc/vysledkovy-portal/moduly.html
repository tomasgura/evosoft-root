CLI Commands cron joby

app:get-tournaments

  • Stáhne seznam turnajů z Flexii API
  • Zkontroluje dt_upd_attributes oproti lokálnímu stavu
  • Stáhne nové výsledkové soubory při změně
  • Ukládá do public/files/tournaments/{tournament_uid}/

app:get-clubs

  • Stáhne seznam klubů z Flexii API
  • Zkontroluje loga klubů, při změně stáhne nová
  • Ukládá do public/files/clubsLogo/
