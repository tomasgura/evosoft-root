Onboarding pro nového developera — Judo Výsledkový portál

Judo výsledkový portál je webová aplikace pro zobrazování výsledků judistických turnajů, profilů členů a klubů v rámci ČSJÚ. Aplikace je read-only — nezapisuje data, jen je čte z DWH a externích API.

Klíčové koncepty

ITournamentDetailRepository

Rozhraní s dvěma implementacemi:

  • TournamentDetailHajimeRepository — pro live turnaje (is_hajime = true)
  • TournamentDetailDWHRepository — pro archivní turnaje

Datagrid

Dynamická tabulka načítaná přes AJAX. Konfigurace sloupce = PHP atribut #[DatagridColumn(...)] na DTO třídě. JS volá /api/* s QueryParams.

Cache

Všechna data jsou cachována. Při vývoji cache vypni:

EVO_CACHE_ENABLED=false

DWH tabulky

Materializované pohledy — aplikace do nich nepíše. Názvy jsou konstanty v src/Repository/Database/DWH.php.

Časté otázky

Q: Kde se berou data pro turnaje?
Z DWH přes TournamentsRepository. Pro live turnaje (is_hajime = true) se živé zápasy/výsledky berou z Hajime API přes HajimeEndpoint.
Q: Jak přidat sloupec do datagridu?
Přidej vlastnost do RowDTO a oznachu ji atributem #[DatagridColumn(title: 'klic.prekladu', type: 'text')]. Pak přidej překlad do translations/*.cs.yaml.
Q: Jak resetovat cache?
php bin/console cache:pool:clear cache.app nebo nastav EVO_CACHE_ENABLED=false v .env.local.
Q: Jak spustit Flexii sync ručně?
php bin/console app:get-tournaments nebo php bin/console app:get-clubs
Q: Kde jsou loga klubů?
public/files/clubsLogo/{club_uid}.*
Q: Kde jsou výsledkové soubory od pořadatelů?
public/files/tournaments/{tournament_uid}/
